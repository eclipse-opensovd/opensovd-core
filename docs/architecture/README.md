# opensovd-core Documentation
This documentation provides a comprehensive guide to understanding, setting up, and contributing to the `opensovd-core` project. Below is an overview of the folder structure and the purpose of each file:

## Folder Structure
### requirements/
- **TBD**

### architecture/
- **gateway.md** - Describes the gateway mode of operation, including routing logic and communication with ECUs.
- **standalone.md** - Explains the standalone mode and its use cases within the SOVD ecosystem.

### setup/
- **installation.md** - Provides instructions for setting up the Rust environment, installing dependencies, and building the project.
- **configuration.md** - Details the configuration files such as `sovd_server_apps.conf`, explaining their structure and usage.

### usage/
- **running.md** - Offers examples and explanations for running the application using CLI options.
- **testing.md** - Guides users on how to test server availability and simulate client requests.

### development/
- **contributing.md** - Outlines the contribution process, coding standards, and best practices for developers.
- **openapi.md** - Explains how the OpenAPI generator is used in the project and how to regenerate API code.

### faq.md
- Provides answers to frequently asked questions and troubleshooting tips for common issues.

This documentation is designed to help developers and users understand the core functionality of `opensovd-core` and contribute effectively.
